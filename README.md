
# Sales Data Analysis Dashboard

## Overview
An interactive sales analytics dashboard built with Python, Pandas, Streamlit, and Matplotlib.

## Features
- Calculate total sales revenue
- Track total units sold and sales records
- Identify the top-performing product
- Analyze monthly revenue trends
- Compare revenue by product and category
- Filter results by product and category
- View detailed sales records

## Technologies
- Python
- Pandas
- Streamlit
- Matplotlib

## How to Run

1. Install the dependencies:

   pip install -r requirements.txt

2. Launch the dashboard:

   streamlit run app.py

## Dataset
The project uses fictional sample sales data stored in `sales.csv`.

## Revenue Calculation
Revenue = Quantity × Unit Price
